# 命令库（全部实测可用）

## 环境准备

```bash
export PATH="/path/to/adb:$PATH"
export MSYS_NO_PATHCONV=1        # Git Bash 必需，否则 adb pull 远程路径被改写
```

## 采集手机信息

```bash
adb devices
adb shell getprop ro.build.display.id
adb shell uname -r
adb shell getprop ro.boot.flash.locked
adb shell getprop ro.boot.verifiedbootstate
adb shell getprop ro.vivo.os.version
adb shell getprop ro.vivo.hardware.version
adb shell getprop ro.boot.slot_suffix           # A-only 机型为空
adb shell ls -l /dev/block/by-name/ | grep -E 'boot|vbmeta'
adb shell cat /proc/partitions
```

## 固件包操作

```bash
unzip -l PD2217_*.zip | grep -E 'boot.img|metadata|payload'
unzip -o PD2217_*.zip boot.img -d ./out
unzip -p PD2217_*.zip META-INF/com/android/metadata | head -20
```

## 文件传输

```bash
adb push boot.img /sdcard/Download/boot_stock.img
adb pull /sdcard/Download/boot_stock.img ./boot_pulled.img
adb shell md5sum /sdcard/Download/boot_stock.img
```

## 刷入（严格顺序，只刷 boot）

```bash
adb reboot bootloader
fastboot devices
fastboot oem device-info                 # 必须 Device unlocked: true
fastboot flash boot patched.img          # 输出 Sending... / Writing... OKAY
fastboot reboot
```

## 验证

```bash
adb wait-for-device
adb shell cat /proc/modules | grep kernelsu    # 期望: kernelsu 212992 2 - Live (O)
adb shell getprop ro.build.display.id          # 与刷前一致 = 数据未清
```

## 救砖

```bash
adb reboot bootloader
fastboot devices
fastboot oem device-info
fastboot flash boot stock_boot.img
fastboot reboot
```

## 不可用命令（别再试，实测都不支持）

```text
fastboot fetch boot                   → Device does not support fetch command
fastboot getvar max-fetch-size        → Variable Not found
fastboot oem dump / dumpgpt / read    → unknown command
fastboot oem help / list / backup     → unknown command
fastboot oem get_socinfo / sha256     → unknown command
fastboot bbk / vivo <anything>        → usage: unknown command
fastboot flashing lock                → 禁止！会变砖
```

## 常见报错对照

| 报错 | 含义 | 处理 |
|---|---|---|
| `failed to stat remote object` | MSYS 路径改写 | `export MSYS_NO_PATHCONV=1` |
| `no devices/emulators found` | adb 掉线 / 未授权 | 解锁屏幕、重新插拔、`adb kill-server` |
| `Device does not support fetch` | 机型不支持 dump | 走固件包提取 |
| `FAILED (remote: 'not allowed')` | BL 未解锁或分区锁 | 确认 `ro.boot.flash.locked=0` |
| `su: inaccessible or not found` | KernelSU 设计如此 | 正常，不是失败 |
